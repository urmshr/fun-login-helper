# FUN Login Helper

公立はこだて未来大学の SSO へのログインまでの画面操作を補助する Chrome 拡張機能です。

## 機能

- HOPE で未ログインのとき、「ログイン」→「未来大の学生・教職員」と進んで SSO のログイン画面を開く
- SSO のログイン画面でパスワードマネージャーによりユーザー名とパスワードが入力されたらログインを実行する

この拡張機能はパスワードを保存しません。ログイン情報はパスワードマネージャーにより入力されることを想定しています。

## 免責事項

この拡張機能は大学非公式のものです。利用により生じたいかなる損害についても、開発者は一切の責任を負いません。

## 注意事項

- 他人と共有しているデバイスでは使用しないでください。
- ログインに失敗したとき、または HOPE にログインできないまま 10 分以内に 3 回ログインを送信したときは、ログイン補助を一時停止します。HOPE にログインするか、ポップアップの「ログイン制限を解除」を押すと再開します。
- システム変更により正常に動作しなくなる可能性があります。

## インストール

```bash
git clone https://github.com/urmshr/fun-login-helper.git
cd fun-login-helper
pnpm install
pnpm build
```
