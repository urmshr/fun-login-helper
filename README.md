# FUN Login Helper

公立はこだて未来大学の SSO へのログインまでの画面操作を補助する Chrome 拡張機能です。この拡張機能は大学非公式のものです。

## 機能

- ユーザーがログインしていない状態で HOPE を開くと、自動で「ログイン」→「未来大の学生・教職員」と進んで SSO のログイン画面を開く
- SSO のログイン画面で、Chrome のパスワードマネージャーに保存されたユーザー名とパスワードを入力してログインする
- HOPE からログアウトすると、HOPE の「ログイン」を自分で押すまでログイン補助を停止する

この拡張機能はパスワードを保存しません。Chrome のパスワードマネージャーに保存されたパスワードを [Credential Management API](https://developer.mozilla.org/ja/docs/Web/API/Credential_Management_API) で受け取って使います。

## Chrome の設定

この拡張機能は、Chrome の「自動ログイン」がオフのままでも使えます。その場合は、ログインのたびに Chrome の確認画面でアカウントを選びます。

「自動ログイン」の設定や説明ダイアログへの応答は、この拡張機能以外のサイトにも影響します。条件を満たすサイトでは、サイトのスクリプトがユーザーの操作なしに、そのサイトに対応する保存済みパスワードを取得できるようになります。

`chrome://password-manager/settings` の設定によってログイン時の挙動が変わります。

| 設定                                             | ログイン時の挙動                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------ |
| 「自動ログイン」オン                             | 条件を満たせば確認なしでログインする                               |
| 「自動ログイン」オフ                             | 毎回、確認またはアカウントの選択が必要                             |
| 「パスワードの入力時に画面ロックを使用する」オン | 毎回、確認またはアカウントの選択が必要。必要に応じて本人確認を行う |

「自動ログイン」がオンでも、Chrome の説明ダイアログに未応答の場合や、ログイン情報の候補が複数ある場合などは確認が求められます。

特に他人が触れる可能性のあるデバイスでは、「パスワードの入力時に画面ロックを使用する」をオンにすることを推奨します。

## 注意事項

- 他人と共有しているデバイスでは使用しないでください。離席するときは画面をロックしてください。
- ログイン失敗を検出したときは、ログイン補助を一時停止します。また、HOPE にログインできないまま 10 分以内に 3 回ログインを試行した場合、それ以上のログイン処理を停止します。HOPE にログインするか、ポップアップの「ログイン制限を解除」を押すと再開します。
- 大学のシステムの変更や Chrome の仕様変更により、正常に動作しなくなる可能性があります。

## インストール

```bash
git clone https://github.com/urmshr/fun-login-helper.git
cd fun-login-helper
pnpm install
pnpm build
```
